## 1. 项目背景与定位

「诈醒学集」是一个面向**大学生自主学习与项目学习**的 AI 原生学习平台。其底层抽象为通用的「AI 学习集市」：学生发布学习目标 → AI 自动生成可执行的个性化任务包 → 学习过程被自动记录 → AI 陪伴答疑 → 成果提交与 AI 初审 → 成果与任务包在集市共享复用。平台以「反诈智研」为首个完整主题专区，但能力可扩展到 Python、高数、考研、毕设等任意学习主题。

定位边界（硬性合规）：
- 仅用于安全教育与风险提示，**不替代**公安 / 金融机构 / 学校的正式判断；
- **不采集**真实姓名、手机号、身份证号等敏感个人信息；校园登录仅以「学号 + 学校」作为匿名身份锚点（不存储姓名/证件），满足赛道#30「学号/校园统一认证」要求，正式环境可对接学校 CAS / OAuth 统一认证；
- 核心能力可**离线运行**：AI 调用走 OpenAI 兼容 API，未配置密钥时自动降级为规则引擎。

## 2. 目标用户

- 核心：高校在校大学生（自主学习、项目学习、考证备考、职业能力成长）；
- 扩展：教育技术团队、学生社团、辅导员（管理端 / 班会素材）；
- 角色：学生（owner）、辅导员（counselor）、平台管理员（admin）。

## 4. 非功能需求

- 性能：SQLite 单库本地读写，演示场景无并发压力；关键路径均有索引（owner_id 等）。
- 安全：演示态 token；失败开放的管理端可在设密钥后校验；不存储敏感个人信息（校园登录仅学号+学校匿名锚点）。
- 可用性：Docker `restart: unless-stopped` 崩溃自启；健康检查。
- 合规性：数据脱敏、规则引擎降级、边界声明（不承担报名/组织职能）。

## 5. 验收标准（按等级）

- **作品级**：交互原型覆盖核心流程（已远超）。
- **产品级**：产品化打磨 + 手册 + 后台 + 四级审核（部分达成）。
- **项目级（本目标）**：① 可稳定运行完整系统底座 ✅；② 内置 ≥10 套任务包 ✅（12 套）；③ 全套项目文档（本册 + 数据库设计 + 部署手册 + 测试报告）✅；④ 可独立部署交付 ✅；⑤ 未大规模内测（符合）。
- **商品级**：需 ≥50 名真实学生试用 + 运营方案（后续）。

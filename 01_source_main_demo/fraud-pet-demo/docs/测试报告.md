2. **集市互动写入**：点赞/收藏当前为计数整型，可写交互接口（按用户记录）与评分/评论为补齐计划项。
3. **校园认证**：当前为演示态登录，学号/统一认证为补齐计划项。
4. **协作管控**：项目式团队分工/节点验收模型未上线（补齐计划中）。
5. **时间 API 告警**：`datetime.utcnow()` 建议迁移至 `datetime.now(UTC)`，无功能影响。
